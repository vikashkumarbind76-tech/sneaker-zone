# Sneaker Zone

India-focused online destination for authentic sneakers, casual shoes, and streetwear.

**Live website:** https://sneaker-zone.lovable.app

## Tech Stack

- Vite
- TypeScript
- React
- Tailwind CSS
- shadcn-ui

## Local Development

```sh
# Install dependencies
npm install

# Start the dev server
npm run dev
```

Build for production:

```sh
npm run build
```

## Custom Domain

A custom domain can be connected through the project hosting settings.
